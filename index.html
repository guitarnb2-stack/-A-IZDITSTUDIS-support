Welcome to A*IZD IT STUDIO

A*IZD IT STUDIO brings together AI-assisted creativity, digital image creation, AI conversations, and multimedia features in one creative environment.

This Support Centre provides general guidance for using the application's available features and finding help when you encounter a problem.

AI Image Creation

Use the image-generation feature to explore visual ideas with text prompts. Describe the image you would like to create and follow the controls available in the app.

If image generation does not work, check your internet connection when required, review any message displayed by the app, and try again.

AI-generated images may not always match the intended result. Review generated content before using or sharing it.

AI Conversations and Questions

The AI conversation feature allows you to ask questions, explore subjects, and receive AI-generated responses.

AI responses can sometimes be inaccurate, incomplete, or out of date. Verify important information using reliable sources.

Image Organisation

Use the image archiving and organisation features available in the application to manage your creative content.

Available options may depend on the app version. Do not assume that content is backed up online unless the app explicitly provides that functionality.

MP3, MP4, and Equaliser Features

The application supports importing and playing compatible personal MP3 and MP4 files, with multimedia organisation and an equaliser interface.

If you experience a playback problem:

  • Check that the file is in a supported format.
  • Confirm that the file is available on your device.
  • Check any device permissions requested by the app.
  • Close and reopen the app if playback stops responding.

Compatibility can vary depending on the file and device.

Troubleshooting

If a feature is not working as expected, try these steps:

  • Check your internet connection for features that require it.
  • Check whether an update for the application is available.
  • Close and reopen the application.
  • Check relevant device permissions if a feature requires them.
  • If the issue continues, contact support by email.

These steps may help with common issues but cannot resolve every technical problem.
